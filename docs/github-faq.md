# GitHub app — quick answers

Live check for temper's GitHub app. Not to be merged.

- **How do I call on temper in a comment?** Write `@shine-temper` and what you want.
- **Can it merge my pull request?** No. It opens pull requests and reviews them with comments only.
- **Who can start it?** The accounts listed under `allowed_authors` in `configs/github/github.yaml`.
- **Does a new pull request get reviewed by itself?** Only when `github_pr_review` is turned on.
