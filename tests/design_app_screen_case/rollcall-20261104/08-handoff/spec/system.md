# System status (More > System status) — spec for Frontend

Draft A v3 direction (Show&Tell d_kgrxir5ezb). Prototype: `draft-a/index.html` → More → System status (`screens['more:system']` in `draft-a/src/screens/system.js`). Data: `fixtures/system.json`. Check: `node draft-a/check-robinhood-system.mjs` (exit 0).

## What it is

Today's System page (Audit, Activity, Health, Metrics tabs) turned around so the first view answers one question: **is everything working?** One line says "Everything is working." or "2 problems need a look.", with a dot per part. Each problem then gets its own card saying what it means and what to do. The four tabs sit below, Health first.

Privacy: show nothing today's page doesn't already show. No tokens, keys, passwords, hostnames, ports or stack traces anywhere on this page, error states included. Today's Metrics footer line naming the metrics token is dropped (see "Removed or renamed").

## Behaviours

- Click feedback before any reply: "Check now" → disabled "Checking…" with spinner, then "Checked just now"; "Retry now" → "Retrying…", then "Still no answer. Next try in 1 min." (`role="status"`) if still down; "Scan now" → "Scanning…", then "Scan couldn't finish: market data still down."; "Check again" (chain) → "Checking…", then "4,812 entries checked just now"; "Load 50 more" → "Loading…"; "Try again" → "Trying again…"; "Try metrics again" → "Reading…". Busy buttons are `disabled` + `aria-busy` and ignore a second click.
- Auto-refresh every 30 seconds as today (no toggle on screen; the tip says it). A refresh never closes what you opened or moves the scroll.
- Tabs keep their own state (open tile, filters, search, open entry) while you switch.
- Searches filter as you type and keep focus and caret. Nothing matching → "No entries match “x” in Settings." + tonal "Clear search and kind" (Activity: "No records match." + "Clear filters").
- One open item at a time per list (tile, record, entry); each opener is a button with `aria-expanded`.
- "See it" on a warning switches to Activity, clears its filters and opens that record.
- One solid primary per view: only "Try again" on the error card. Everything else is tonal or ghost (this page is for reading).
- Owner-only views (tenant filter, server-wide scope) stay as today; the scope line on Metrics says whose numbers they are.
