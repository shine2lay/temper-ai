# Pain-voice signal — 2026-10-02 scan: 4 candidates

Venue coverage note up front: the electrical/home-services trade forums (electriciantalk.com,
contractortalk.com) are open and load normally, and host exactly the right threads by topic
("Answering the phone," "Have you used an answering service?," "Customer no show to service
appointment," "Potential Clients who get mad") — but every thread found under missed-call /
answering-service / no-show keywords is dated 2015-2024, with zero posts on/after 2025-04-01.
That is itself a finding, not just a gap: it means the richest expected venue for Candidate 1
did not yield a single recent complaint, despite trying multiple keyword angles. For the
REFERENCE candidate, the opposite problem recurs from the prior screening round noted in project
memory: no accessible trade forum exists at all for IRF/LTCH admissions/UR/billing staff, so the
richest on-target source found (a physician forum) is substantively perfect but dated 2023.

## Sources and method

- **HN (Algolia API):** multiple phrasings tried per candidate (missed-call/answering-service
  language for Candidate 1; claim-denial/prior-auth/revenue-cycle language for Candidate 2;
  bookkeeping-client language for Candidate 3; Medicare Advantage/rehab language for the
  REFERENCE). Returned mostly off-target general commentary or vendor "Show HN" posts; no counted
  quotes came from HN for any candidate.
- **Stack Exchange API:** one query each on `money` (Candidates 2 and 3, the closest-fitting
  site) returned 0 recent hits both times; no SE site exists for electrical trades or medical
  billing specifically, so none was queried for Candidates 1 or the REFERENCE.
- **App Store review RSS:** the strongest channel for Candidate 1 — Housecall Pro, Jobber, and
  ServiceTitan Mobile/Field app ids were found via `app-search` and their 1-3 star reviews pulled
  via `app-reviews`; this produced the only counted quotes for that candidate. Not used for
  Candidates 2/3/REFERENCE (no obvious single consumer-facing incumbent app fits those jobs as
  cleanly).
- **Trade forum pages (`voc.py page`):** electriciantalk.com and contractortalk.com load normally
  and were the most promising venue for Candidate 1 by design, but every on-topic thread found was
  pre-2025. AAPC Discuss (aapc.com/discuss) loaded normally and gave the only counted quotes for
  Candidate 2. medicalbillingandcoding.org/forum/ (404) and forums.mikeholt.com (403) were tried
  and logged inaccessible. Student Doctor Network's forums.studentdoctor.net loaded normally and
  gave the REFERENCE candidate's best (but too-old) corroboration.
- **WebSearch snippets:** used to find forum thread URLs (primary use, not quoted directly) and,
  per the brief's allowance, once per candidate to probe G2/Capterra/Reddit. Reddit consistently
  returned zero reddit.com results across every query tried (7 queries across all 4 candidates).
  G2/Capterra queries returned paraphrased marketing/review-summary pages rather than quotable
  verbatim text in every case tried.
