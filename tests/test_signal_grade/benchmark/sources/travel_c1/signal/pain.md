# Pain-voice signal — travel discovery-by-preference shortlist (V1-V4)

Researched 2026-10-03. Helper: `voc.py` (HN Algolia, Stack Exchange API, App Store
review RSS, and direct page reads of forums that load normally). No WebFetch used;
quotes below are copied verbatim from `voc.py` output or from WebSearch result text
that itself contained quotation marks (tagged "snippet").

## V1 — AI-chat trip planner for leisure travelers (CONSUMER)

"doesn't know my budget", "where do I even start", "AI gave me the same list",
"it made up a restaurant", "ChatGPT got it wrong", "too many tabs open". Incumbent
apps: Wanderlog, TripIt, Mindtrip, Layla, Google/Gemini. Venues: community.ricksteves.com,
fodors.com/community, App Store reviews of the above apps, HN, SE travel.

incumbent apps, Fodor's Travel Talk Forums, Rick Steves Travel Forum).

## Sources and method

- **App Store review RSS** (via `voc.py app-reviews`) was the single richest
  source across all four versions — exact text, exact dates, and for V1/V3 the
  incumbent apps ARE the target user's daily tool, so 1-3★ reviews are
  first-person job complaints almost by construction.
- **Rick Steves Travel Forum** (community.ricksteves.com) loaded normally and
  gave dated, first-person consumer posts for V1/V2; **Fodor's Travel Talk
  Forums** (fodors.com/community) also loaded normally and gave one good recent
  (Oct 2025) AI-itinerary-skepticism thread for V1, though most Fodor's threads
  WebSearch surfaced were years old.
- **Host Agency Reviews** (hostagencyreviews.com) and **Reviews.io**
  (reviews.io/company-reviews/store/travefy) both loaded normally and were the
  only two venues that gave first-person advisor complaints for V4; both are
  about the same vendor (Travefy), which is the gap flagged above.
- **Hacker News** (Algolia API) returned mostly startup founders pitching their
  own travel tools or unrelated stories (travel advisories, HN's generic
  "advisor" usage) rather than target-user complaints, for all four versions —
  read thoroughly, almost nothing counted.
- **Stack Exchange travel** (API) had very low relevant hit rates (0-9 hits per
  query, nearly all off-target) — consistent with the brief's warning that SE
  rarely covers these niches.
- **WebSearch** was used to find forum threads to then read with `voc.py page`,
  and as a last resort for G2/Capterra/reddit snippets; reddit.com yielded zero
  results across every query tried (consistent with the documented constraint),
  and G2/Capterra yielded only paraphrased summaries, not quotable verbatim text.
- Nothing was retried through a proxy, cache, alternate front-end, or any other
  workaround after a block; every inaccessible/empty result is logged inline
  above at the point it was encountered.
